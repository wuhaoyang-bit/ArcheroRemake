# 怪物训练场：软体 / 硬体切换

怪物训练场右下角显示「软体/硬体切换」，并标明当前模式。每次重新打开页面默认硬体；在同一会话内离开、返回训练场会保留当前模式。

硬体使用当前配置。软体以提交 `2f553d08685672d08b41d39f58c197619b213bf9` 的史莱姆参数为起点，恢复原先的充盈、蓄爆与移动液路等表现。历史参数摘录位于 `src/presets/slime-soft-2f553d0.json`。切换是参数预设切换，不回退旧游戏代码。

两种模式共享并保留以下当前值：

- 「射箭 · 特效与后坐力」整组，包括弓箭、颜料球、出箭特效、拖尾、后坐力及其曲线。
- 「受击 · 反馈与调试 / 受伤 · 跟随汁滴」全部参数，包括数量、大小、高度和开关。
- 移动、锁定、房间、镜头跟随、音频、怪物数量和追赶速度等非史莱姆表现参数。

切换白名单包含史莱姆体型/运动形变、眼球、受击形变、爆炸、地面液体、移动液路及相关相机反馈，怪物模型缩放也随预设切换。跟随汁滴明确从白名单排除。

晚于历史参数快照加入的白名单效果开关在软体期间强制关闭，目前为爆炸碎块及其线框；侧边栏对应开关会禁用。其余历史效果按预设恢复。切换会重置训练怪物，并清理在途箭矢、眼球、碎块、液体、喷溅和镜头反馈，避免两套效果混合。

两套模式分别保留调参。保存 JSON 时，顶层 `settings` 始终保存硬体及共享参数，`slimePresets.soft` 保存软体参数。因此在软体中保存也不会将下次启动变成软体。旧调试页仅保存顶层参数时，服务端仍保留已有软体预设。切换本身不自动写文件。

撤回仅针对当前模式；跨模式切换时重建当前模式的撤回历史，撤回全部回到该模式的最近保存基准。切换前的调参仍保留在对应模式，不会因切回而丢失。

验证：17 项参数/预设/撤回测试通过；Chrome 验证历史值、保护参数、独立调参、爆炸中切换清理、软体禁止生成碎块、保存重载默认硬体，以及桌面/390px 手机布局。截图位于 `analysis/slime-presets/`。浏览器验证使用拦截的参数和保存接口，不写用户调参文件。
