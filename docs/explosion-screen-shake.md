# 爆炸屏幕震动实验

游戏左侧「侧边栏类型 → 爆炸 · 屏幕震动」提供总开关、爆炸使用档位与游戏内预览。档位只有一个选择入口，同时驱动实际爆炸、参数编辑、曲线和预览；刷新与撤回也从保存设置读取同一档位。默认开启中档；每档参数独立，支持现有「保存参数」「撤回一步」「撤回全部」。旧参数文件自动补齐默认值，不覆盖已保存的其他调参。

移植来源：`SmashBroCER/src/combat/cam-shake.ts` 的 `envelopeA` 与 `camOffset`。弱档仅纵向，中档横纵交织（X 频率为 Y 的 1.5 倍），强档衰减圆形；中／强每次重新随机起始相位。沿用 60 Hz 取样、默认时长 9 帧及 2 / 4 / 8 px 振幅。弱／中默认 Remain^p，强默认 Trauma^n；p=3、n=2、ω=0.9 rad/帧、Trauma 衰减量=1/9。此处没有格斗卡帧绑定，持续帧数可独立调整，修改时同步衰减量为 1/M，之后仍可手动微调。

在 `TrainingFeedback.onBurst` 真正爆开回调中读取当前震动配置并触发一次，受击和蓄爆期间不触发。连续爆炸重新开始一个脉冲，不叠加振幅。配置在触发时固定；关闭立即归零，重置怪物、切换训练场或重建房间时清理。

振幅以 390 px 宽的游戏画面为基准等比缩放。通过相机投影偏移移动世界画面，锁定圆环使用同一投影跟随；操控轮盘、调参 UI 和实际角色/怪物坐标不位移。可与原有屏幕伸缩同时启用，震动幅度不受缩放倍率影响。暂停、慢放和逐帧使用游戏模拟时钟。

本实验接入游戏画面；原 `slime-burst-lab.html` 仍作为独立模型与特效观察页。

验证：`npm test`、`npm run build`、`node tools/camera-shake-browser-check.mjs`。浏览器验证涵盖真实爆开时序、三档参数、预览、保存/刷新/撤回、暂停和重置、镜头缩放、世界坐标及手机布局；拦截参数保存，不修改实际 `public/params.json`。
