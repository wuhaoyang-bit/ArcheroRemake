## 1. 预览（侧视 2D）→ 游戏（俯视 3D）映射

预览页是**侧视**：箭左右飞，C 画在纸面里。  
游戏是**俯视**：相机朝下，可读的「月牙」必须发生在**地面平面**。

| 预览 2D | 游戏俯视 3D |
|---|---|
| 纸面左右 = 受力/击退 | 世界 XZ 中沿箭方向与其水平垂直方向 |
| C 内部朝左（箭来侧） | C 内部朝**水平迎箭方向**（箭飞来的一侧） |
| 中段向右弓（击退侧） | 中段向**水平击退方向**弓出 |
| 脚钉地 | 网格底部（局部 y≈0 附近）水平位移≈0 |
| 高度方向分节 | 用局部 **y（脚→顶）** 作弯曲权重；**峰值权重落在眼睛高度** |
| 方案 A 上半再转 | 对 y 高于腰线的顶点，绕竖直轴再增加朝击退侧的转角/切向位移 |
| 过冲弹回 | 弯曲权重用欠阻尼弹簧回到 0，允许短暂越过 |

**合成顺序（拟定）：**

1. 用 rest 顶点做水平月牙弯曲（局部空间，脚权重≈0，眼高附近权重最大）  
2. 再乘现有 `hitDeformation`（方向压缩 + 补偿）与模型缩放  
3. 根节点仍由 `HitResponse` 做击退平移  
4. `face`/眼睛：挂点取弯曲后「眼睛高度」采样位置；**其上再叠现有 eye-hit**，不改 eye-hit 曲线本身  

若实现中发现眼睛与身体错位，只校准挂点，不擅自改 eye-hit 参数语义。

## 2. 完成效果需要哪些模块

### 2.1 新建

| 模块 | 职责 |
|---|---|
| `hit-bend-config.ts`（名可调） | 开关、成 C 用时、最大弯曲、后仰延迟/用时/幅度、弹回频率/阻尼、脚锁高度、眼高对齐；LIMITS + 面板文案 |
| `hit-bend.ts`（名可调） | ① 时序权重 `belly` / `upper`（对齐预览三拍）；② 将权重写成 body 顶点水平位移；③ rest 顶点缓存与复位 |

### 2.2 改动（现有）

| 模块 | 改动 |
|---|---|
| `yellow-slime-model.ts` | 暴露 body 几何、rest 顶点副本或可写 position attribute；保证可每帧写回 |
| `training-feedback.ts` | 史莱姆受击路径：在应用 `hitDeformation` 前/约定顺序内调用弯曲；非史莱姆跳过 |
| `hit-feedback-config.ts` / `HIT_CONTROLS` | 挂上弯曲参数（仅史莱姆相关文案标明） |
| `settings-store.ts` / `controller.ts` / `main.ts` | 读写、保存、侧栏控件 |
| `tests/hit-feedback.test.ts` 或新测 | 时序权重、脚底水平位移≈0、非史莱姆不受影响、与压缩叠加不互相清零 |

### 2.3 保持不动（本功能）

- `hit-response.ts` 击退位移与弹簧缩放时钟（弯曲权重可复用其命中年龄，或自管时钟但**命中快照**规则与现有一致）  
- `hit-deformation.ts` 方向压缩公式（叠加，不改语义）  
- eye-hit 曲线与滞留逻辑（只跟挂点）  
- 2D 预览页可继续作对照，不强制接入构建流水线  

### 2.4 数据流（概念）

```
命中 → 记录箭水平方向 + 重置弯曲时钟
每帧：
  age → belly/upper 权重（成C / 后仰A / 过冲弹回）
  rest顶点 + 权重 + 方向 → 水平月牙位移（脚≈0，峰值在眼高）
  再 hitDeformation(方向压缩)
  根节点 HitResponse 击退
  face 挂到眼高弯曲采样点 + 原有 eye-hit
```

## 3. 实现步骤（建议顺序）

### 步骤 A — 时序与参数（无渲染也可测）

1. 落地 `belly` / `upper` 权重函数，行为对齐预览：  
   - `[0, tC]`：belly 0→1，upper=0  
   - `(tC, tC+delay]`：belly=1，upper=0（delay 默认 0）  
   - `(tC+delay, tC+delay+tFollow]`：belly=1，upper 0→1（方案 A）  
   - 之后：两者欠阻尼弹回 0，允许过冲  
2. 单测覆盖默认 delay=0、delay>0、过冲符号。  

### 步骤 B — 史莱姆顶点弯曲（静止方向调试）

1. 缓存 body rest 位置。  
2. 实现水平 ⊂：内部朝迎箭水平方向；峰值在眼睛高度；脚层水平位移≈0。  
3. 在训练场用固定方向箭命中，俯视检查月牙朝向；侧视/斜视只作辅助。  

### 步骤 C — 与方向压缩、击退、眼睛合成

1. 约定矩阵/顶点顺序并写进代码注释（与本 PLAN 第 1 节一致）。  
2. 叠加现有方向压缩，确认两者同时可见。  
3. 击退根节点平移不因弯曲重复叠加。  
4. face 挂点跟眼高弯曲采样；eye-hit 原样叠加。  

### 步骤 D — 方案 A 上半再转

1. 在 belly 已满后，对腰线以上增大朝击退侧的转角式位移（A，不是 B 拉长弧）。  
2. 与预览 A 栏对照读感（俯视为主）。  

### 步骤 E — 调参面板与持久化

1. 侧栏「受击 · 反馈」下增加史莱姆弯曲一组控件。  
2. `params.json` 缺省继承；不覆盖用户其它字段。  

### 步骤 F — 验收

1. 俯视：月牙内部朝箭来侧。  
2. 三拍可辨：成 C → 上半再转后仰 → 过冲弹回。  
3. 脚底不「滑步式」横移（相对根节点）。  
4. 仅史莱姆生效；蜘蛛等不变。  
5. 方向压缩、亮边、击退、eye-hit 仍可用。  
6. 连击：与现有受击一致——新命中重新快照/重开时钟（若与现网不一致，**先问再改**）。

## 5. 风险与仍须开口确认的点

1. **连击重触发**：弯曲时钟是否与 rim/squash 一样「每次命中重置」——默认按现有受击习惯，若你要不同请说。  
2. **鼓胀 / 呼吸 / burst 缩放**：与顶点弯曲叠加顺序若出现穿模或脚漂，再单开一轮对齐，本 PLAN 不预先改那些系统。  
3. **性能**：仅史莱姆、单 mesh 顶点写入；若日后扩到多怪再评估。  
4. **预览 B 方案**：本 PLAN **只做 A**；B 不实现除非另批。
