# 液滩形状观察页

入口为 `puddle-shapes.html`，游戏「撑爆 · 液体残留」及爆炸调试页均提供链接。

- 查看三种 CurveFluid 游戏网格和三种旧版原始笔刷轮廓；并排或单独观察。
- 拖动旋转、滚轮缩放，提供俯视、透视、低角度、线框和自动旋转。
- 两种渲染方式分别勾选随机候选，每种至少保留一个。
- 保存前重新读取游戏设置，仅更新两组候选并将 `puddleShape` 设为0（随机），保留当前渲染方式及其他参数。刷新游戏/调试页后生效。

`puddleCanvasShapes` 与 `puddleCurveShapes` 是三位掩码（1、2、4分别对应形状1、2、3），默认7全部启用。游戏在生成液滩时根据当前渲染方式，从对应池中等概率抽取。已生成液滩不会因修改候选池而重新抽取；用户后来手动指定固定形状时，该固定选择优先。

页面仅加载三维液滩和笔刷资源，不加载空中爆炸的26 MB动画数据。旧版预览用于观察原始笔刷，实际游戏仍会应用噪声边缘等材质效果。

验证：`tests/puddle-shapes.test.ts` 覆盖全部非空候选组合、固定形状优先级及保存兼容；`tools/puddle-shapes-browser-check.mjs` 检查观察交互、保存合并、独立候选池、实际生成路径和手机布局，保存请求被拦截，不更改用户参数。
