# 当前阶段：颜料注入与史莱姆撑爆

记录日期：2026-10-28。状态：黄色软胶方块已接入游戏；累计注入、外鼓形状与弹性响应已接入怪物训练场；内部紫色颜料可视化和撑爆尚未制作。

## 已确认设定

- 箭头不是铁质箭头，而是一袋透明颜料袋，内部装紫色颜料。
- 敌人是黄色、柔软的史莱姆。黄色替代先前提到的绿色。
- 每次箭命中，将袋内紫色颜料注入史莱姆，累计增加体内颜料含量。
- 体内紫色颜料越来越多与身体逐渐被撑大，两种变化都需要视觉呈现。
- 用户已纠正“体内黄色颜料变多”的口误，正确设定是体内紫色颜料增多。
- 按累计注入量 / 容量实现；达到容量后，史莱姆因颜料过多而爆开。
- 本阶段核心目的：制作“打入 → 注入 → 撑胀 → 撑爆”的打击手感。

## 建议起点（助手建议，尚未确认实现顺序）

先在现有训练场制作一只黄色史莱姆的最小可玩闭环：实际箭命中后增加注入量，体内紫色区域随填充率增长，身体同步膨大，达到容量后播放简易撑爆并退出目标选择。提供重置用于重复比较。

优先验证正常游戏镜头和手机尺寸下，玩家是否看得出“紫色颜料在体内积累”和“身体越来越满”。随后细化局部注入、软体受击、临界鼓胀和爆开节奏，最后完善透明颜料袋箭头的材质和细节。

建议开放每箭注入量、容量、最大膨胀倍率；具体初值与增长曲线待试验，不作为已确认规则。

- 身体透明度、黄色身体与紫色颜料的视觉层次；尚未约定混色规则。

这些细节不影响上述核心设定，后续方案需区分已确认规则与试验建议。
