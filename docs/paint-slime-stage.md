# 当前阶段：颜料注入与史莱姆撑爆

记录日期：2026-10-28。状态：黄色软胶方块已接入游戏；累计注入、外鼓形状与弹性响应已接入怪物训练场；撑爆流程、六层特效、地面液体及弹簧展开已接入；同色颜料由淡黄逐渐过渡到原黄色的表现已接入。

## 已确认设定

- 箭头不是铁质箭头，而是一袋透明颜料袋，内部颜料与命中的怪物同色，当前为黄色。
- 敌人是黄色、柔软的史莱姆。黄色替代先前提到的绿色。
- 每次箭命中，将袋内同色颜料注入史莱姆，累计增加体内颜料含量。
- 身体随注入逐渐被撑大。颜色规则已改为同色颜料积累使颜色加深，不混色；颜色已随充盈比例从淡黄平滑过渡到原黄色。
- 最新同色设定覆盖此前的紫色颜料方案；爆开特效和液滩默认均为黄色。
- 按累计注入量 / 容量实现；达到容量后，史莱姆因颜料过多而爆开。
- 本阶段核心目的：制作“打入 → 注入 → 撑胀 → 撑爆”的打击手感。

## 已确认的撑爆流程（2026-10-28，最新确认，已接入游戏）

### 1. 充满与最后一箭的完整反馈

- 本次箭命中使累计注入量达到容量后，立即退出可锁定目标列表；玩家自动切换其他有效目标，不存在目标则解除锁定。
- 从充满开始不再接受额外伤害/注入；后续箭矢可穿过，不遮挡其他目标。
- 最后一箭必须完整播放既有受伤反馈，包含原有击退，不能为了“原地停下”而截断击退。
- 停止自主移动；最后一箭的击退仍正常执行，击退结束后保持在该位置，不恢复自主移动。
- 完整受伤反馈播放完毕后，才进入蓄爆动画。阶段完成以实际反馈状态为准，不能写死一个与受击参数脱节的等待时间。
- 保留现有受伤缩放/方向压缩、弹性鼓胀的兼容要求；进入下一阶段从实际外形连续接续。

### 2. 原地蓄爆

- 反复放大、缩小，往返频率随时间增加。默认只提高频率，幅度单独设置起止值与变化曲线。
- 同时基础体积缓慢增大，鼓面程度逐渐增加；往返伸缩、基础体型增长和鼓面增长三项独立叠加。
- 从蓄爆开始时的实际外形接续。鼓面目标默认 0.8，开放调整；若进入时已超过目标，不因目标较低而反向收缩。
- 默认在最后一次向外鼓起的峰值让模型消失，避免任意相位截断；开放结束相位控制。
- 蓄爆时长与最终增大倍率开放调整，具体默认值尚未确认。

### 3. 爆开与液体残留

- 蓄爆结束时模型瞬间消失，不做模型透明淡出。
- 默认同时在身体中心播放已确认的 Lush 命中特效，并在脚下地面生成液滩。
- 特效和液滩的触发延迟与位置偏移分别可调。
- 所有爆开特效及液滩默认均为黄色。液滩“黄色”指颜色，不是笔刷形状。
- 液滩默认在三种原始飞溅形状中随机选择，随机旋转。
- 液滩生成时使用项目已有弹簧模型从小变大，超调后真实回缩至目标轮廓。
- 液滩默认持续保留到训练场重置；重叠沿用当前覆盖规则。颜色、形状、寿命、淡出等可调。

## 参数开放要求（实现验收项）

尽可能暴露上述各过程的全部表现参数，不将影响手感的关键值硬编码。已确认的目标选择/穿透/阶段先后是流程规则，不必为每个规则增加可破坏流程的开关。

- 最后一箭反馈：沿用现有受击、击退和弹性鼓胀设置；修改这些设置后，蓄爆开始时机随实际反馈完成时间同步变化。
- 阶段时序：蓄爆目标时长、阶段衔接时间、结束相位；默认等待最后一次向外鼓起的峰值。界面需要明确时长与相位如何共同决定实际结束时间。
- 往返伸缩：初始/结束频率、频率变化曲线、初始/结束幅度、幅度变化曲线、起始相位、结束相位及需要的轴向控制。
- 基础体型：最终增大倍率、增长时间范围、增长曲线。
- 鼓面：目标程度（默认 0.8）、增长时间范围、增长曲线；保持不反向收缩的默认规则。
- 爆开特效：独立延迟、位置偏移、整体大小、播放速度、颜色；各效果层的开关及可支持的数量、寿命、运动、尺寸、透明度与材质参数。
- 液滩：独立延迟、位置偏移、形状选择/随机范围、旋转/随机范围、颜色、目标尺寸、起始尺寸比例、弹簧频率、阻尼、初始速度、播放速度，以及材质参数、保留时间和淡出过程。
- 涉及曲线的部分提供可视化；提供暂停、重播与恢复默认，便于逐阶段比较。设置应持久保存。
- 本次已接入流程、参数持久化及两套可播放/拖动的曲线预览。蓄爆时长 1.2 s、基础倍率 1.2 为可调试验初值。粒子数量从烘焙样本筛选，播放速度同步控制寿命和轨迹；未提供独立改写烘焙粒子发射器的接口。

## 衔接时机更新

用户新增允许提前蓄爆：`burstFeedbackDelay` 支持负数（-10～3 秒），含义为相对最后受击反馈结束的时间偏移。负值允许受击与蓄爆重叠，覆盖原先必须完整等待的要求；默认 0 仍完整等待。重叠期间击退、受击缩放、闪光与弹性鼓胀继续推进。游戏和逐帧调试页同步支持。

## 充盈变色与行走（最新）

- 初始颜色 #fff4b1，满容量颜色为原来的 #ffdd32；按实际注入量 / 容量平滑变化，不跟随弹性鼓胀的超调回缩。同步调整透射吸收颜色，使初始浅色不被原来的深黄吸收色覆盖。
- 严格超过 50% 后，默认自主移动速度乘 0.65；不改变击退速度。阈值和倍率可调。
- 超过阈值并实际移动时，默认 1.2 Hz、±4% 的整体呼吸伸缩；0.15 秒渐入/渐出。碰撞完全阻挡、停止行走、击退和充满退出追赶时淡出。
- 呼吸叠加原有两种受击形变、累计鼓胀及提前蓄爆，不改变命中代理；脚底保持接地。颜色与呼吸均按每只怪物独立维护，重置清空。
- 「史莱姆 · 充盈变色与行走」开放起止 RGB、颜色过渡时间/曲线幂次、阈值、减速开关/倍率、呼吸开关/频率/幅度/起止过渡；支持原参数保存流程。爆炸调试页也能调参，但其静止预览不触发行走呼吸。
- 验证：201 项测试、构建与 Chrome 真实模型的 0% / 60% / 100% 充盈、移动速度、呼吸停止及重置检查通过。
