# 怪物爆炸逐帧调试

入口：`slime-burst-lab.html`；游戏参数面板「史莱姆 · 蓄爆」也提供入口。

- 复用 `TrainingFeedback`、`SlimeBurstState`、黄色方块模型与 `LushBurstEffects`，独立观察最后受击、蓄爆、模型消失、六层特效和液滩。
- 初始填充为容量减去一箭注入量，随后执行一次实际命中；第 0 帧为命中瞬间。关闭撑爆/注入或注入量为零时，遵循游戏规则，不强制生成爆炸。
- 模拟以 120 Hz 推进。可选择每次按 120/60/30 fps 步进；支持时间轴、帧号、前后步进、慢放、循环、阶段跳转，以及空格/左右方向键。
- 倒退通过重放相同初始状态实现；液滩随机种子固定，可独立修改。粒子使用游戏相同的烘焙动画。时间轴末尾默认在爆开后 4 秒，可延长至 120 秒查看残留和淡出。
- 参数修改后暂停并重算当前时间。输入支持筛选；尺寸曲线支持独立预览。六层开关与参数均使用游戏配置。
- 「爆炸 · 空间扭曲冲击波」复用游戏中的环形折射效果，支持独立范围、时长、强度、衰减和扩散速度曲线；逐帧倒退会重建同一波带。详见[冲击波说明](explosion-shockwave.md)。
- 初次读取游戏保存参数。只有「保存到游戏」会写入参数文件；保存时重新读取并合并本页相关字段，保留其他游戏设置。游戏页需刷新读取。另支持 JSON 导入/导出与恢复本页默认。
- 独立摄影机支持透视、正面、侧面、俯视及自由旋转缩放。为观察模型细节使用中性地面和独立取景；不模拟角色射箭、锁定、镜头冲击及普通命中的汁液粒子。

验证：`node tools/slime-burst-lab-check.mjs` 检查阶段边界、消失前后帧、倒退重放一致性、步进单位、参数重算、保存合并、播放暂停与窄屏布局。测试拦截参数保存，不改写实际游戏配置。

## 提前衔接

「受击 → 蓄爆时间偏移」支持 -10 到 3 秒。-0.5 表示比受击反馈全部结束提前约 0.5 秒开始蓄爆；0 保持原流程；正数表示额外等待。最早从最后一箭命中开始，不会倒回命中前。剩余击退、受击缩放/闪光和弹性鼓胀继续与蓄爆叠加，直至自身结束或模型爆开。弹簧完成时刻按游戏 120 Hz 的静止阈值预测，时间轴标记采用同一逻辑。默认仍为 0，旧参数保持兼容。

## 蓄爆伸缩变色

游戏「怪物爆炸 · 动画与特效 → 史莱姆 · 蓄爆」和本页「蓄爆节奏与形态」共用「蓄爆伸缩变色」开关及「蓄爆颜色变化幅度」。默认开启、幅度 4%，膨胀略亮、收缩略深；保留当前充盈颜色的色相与饱和度，仅调整 sRGB HSL 明度，最大增减 4 个百分点。

颜色使用与蓄爆缩放相同的振荡、频率加速和渐入包络，以设定的最大伸缩幅度归一化；伸缩幅度减小时颜色变化也减弱，两端伸缩幅度都为零则不变色。参数在触发蓄爆流程时记录，游戏下次触发生效，本页调参后重算当前帧。仅在蓄爆阶段叠加，普通受击与充盈变色保持原逻辑；每次绘制从基础颜色重算，避免暂停或反复刷新累积变色。爆开与重置时清除颜色偏移，爆开粒子及液滩使用基础充盈颜色。

## 液体渲染方式

`puddleRenderer`：0 为旧版平面粘液（默认），1 为 CurveFluid 三维网格。游戏和调试页均提供下拉选项，切换保留现有液滩状态并支持保存。原有高光、渐变、噪声和阴影设置继续用于旧版。详见[实现说明](curve-fluid-puddles.md)。
