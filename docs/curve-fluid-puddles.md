# CurveFluid 地板粘液

地板残留支持两种渲染方式：0 为旧版 Canvas 平面粘液（默认），1 为 FuLi 的 Curve Fluid v0.0.2 派生网格。游戏「撑爆 · 液体残留」和爆炸调试页「地面液滩」提供下拉选项，支持保存。切换立即作用于已有液滩，保留位置、颜色、年龄及展开状态；两套表面不会同时显示。空中爆开沿用原有资源。

## 资源

`public/assets/curve-fluid/puddle-{1,2,3}.glb` 来自 `CurveFluid.blend` 实际几何节点求值结果的三个连通液片。离线处理包括主平面定向、压低高度、简化网格，以及添加 Gathered 形态键。每种约 1,600 个三角形，三个 GLB 合计约 150 KB。原始文件不包含在游戏包内。

重建（Blender 5.2，需原文件）：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup /path/to/CurveFluid.blend --python tools/export-curve-fluid.py
```

作者与修改声明在 `public/assets/curve-fluid/credits.html`，原文件许可声明在 `LICENSE-source.txt`。游戏液滩设置及爆炸调试页提供署名入口。

## 运行时

CurveFluid 模式下，已有液滩实时读取当前尺寸、随机尺寸范围、偏移、形状、旋转、延迟、弹簧、寿命与淡出参数。重新计算保留爆炸时间及原随机种子，不重启动画；已到期并被移除的液滩不会恢复。刷新缓存涵盖尺寸、位置、旋转、形状及颜色。怪物来源的液滩保留该怪物爆开时的颜色；未提供怪物颜色时，实时读取液滩 RGB 设置。旧版的高光/渐变/噪声仍仅作用于旧版。

`curve-fluid-puddles.ts` 加载三种共享网格，每种一个 InstancedMesh。水平展开沿用弹簧参数，并通过逐实例 morph 从聚拢形态过渡到平铺形态。曲面使用物理材质、场景灯光和阴影。着色法线随网格形变更新；对朝侧面的边缘法线逐渐加入朝上的分量（最大70%），减轻压扁网格在边缘与孔洞周围的暗带，朝上的中央曲面保留原法线与高光。该处理只改变受光，不改变几何形状。室内环境贴图强度设为0，避免整片液面被额外提亮、颜色冲淡；场景灯光仍产生曲面高光。怪物颜色原样传给实例颜色。

最多保留最近 128 个液滩，最多三批主体绘制（阴影另计）。Three r186 的形变着色器要求实例数大于1；某形状只有一滩时，额外放置一个不参与画面的视野外占位实例，保证形变路径稳定。静止液滩不再每帧上传实例数据。延迟、寿命、淡出、随机形状/尺寸/旋转和关卡重置均沿用现有逻辑。淡出采用 alpha hash，避免透明网格排序问题。

旧版高光、渐变、噪声和假阴影参数已恢复到调参界面，仅影响旧版渲染。粗糙度和阴影开关两种模式均有效。

切换模式不删除液滩数据：三维模式显示最近128滩，旧版显示全部有效残留。寿命为0的液滩保留至重置。下文的128上限仅指三维显示数量。

这不是实时流体模拟；相邻液滩不做体积融合。当前保留源液片的孔洞与分叉，不会模拟液体流下台阶。

## 验证

`node tools/puddle-renderer-browser-check.mjs` 检查默认旧版、双向切换、现有液滩状态保留、互斥显示、保存值和清空。保存请求被拦截，不写实际参数文件。

`node tools/curve-fluid-browser-check.mjs` 检查 WebGPU 绘制、可重复倒放、真实高度和 morph、三批实例、128 个上限、延迟/淡出/到期/重置/禁用，以及旧地板对象的移除。预览服务使用 `127.0.0.1:5187`；截图输出到 `analysis/curve-fluid/`。

`node tools/curve-fluid-game-check.mjs` 验证实际训练场的命中、爆开、地面网格、重置与连续射击。两项浏览器检查使用原始文件直送26 MB空中爆开缓冲区，避免开发服务传输限速；网格资源和渲染均使用真实实现。
