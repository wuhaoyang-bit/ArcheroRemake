# 出箭气浪预览器

入口：`/bow-release-lab.html`，开发地址 http://127.0.0.1:5173/bow-release-lab.html。

- 复用 `loadCharacter()`：项目角色、红弓挂点、AttackPrev / AttackEnd 拼接与红弓缩放轨道；箭使用 archero-arrow.glb。
- 固定项目视角复制 scene.ts 的摄像机公式：正交投影，位置 `(0,24,24/tan(asin(.82)))`，看向原点。读取 params.json 的 viewWidth、cameraOffset；宽高比取预览窗口。观察放大 1 倍为游戏视野宽度，额外倍数仅用于观察。
- 自由视角同样采用正交投影，OrbitControls 可转动、缩放、平移。含正面、侧面、正上方快捷视角。
- 以绝对时间采样角色动作与气浪、箭飞行；倒退与重复采样结果一致。逐帧基准可选 30/60/120 FPS，单步后保持暂停。攻击倍率只影响角色动作与出箭时间，气浪寿命独立。
- 固定在出箭位置消散，不跟随弓或箭移动；环带、尖刺、角色、箭分别开关。
- 素材：Kenney Light Masks 1.0，Default/ring_a_streaks.png、Default/cone_e.png；CC0，原许可保存在 public/textures/bow-release/KENNEY-LICENSE.txt。来源 https://kenney.nl/assets/light-masks 。灰度遮罩由 WebGPU TSL 采样，环带径向 UV 宽度变化，单刺交叉网格绕箭轴 360° 排列，尖端朝后并向外偏转（默认 25°），围绕半径默认 0.3 u。材质深度测试开启，深度写入关闭。
- 这是本地遮罩试作，并非原游戏提取效果。原图单环有多个亮斑；当前默认效果已由用户确认。空间方向已对齐：环平面垂直箭轴，法线朝向出箭方向，尖刺环绕箭尾；不使用摄像机朝向的广告牌。原地单次攻击预览不包含游戏中的选敌、连发与动作过渡。
- 调参仅影响本页内存，不写入 params.json，游戏采用共用模块中的确认默认值，预览调参不保存到游戏。
- 验证：npm run build；node tools/bow-release-browser-check.mjs（摄像机公式、加载、触发、反向采样、逐帧、暂停转视角、开关、移动布局、参数文件保持不变）。

补充验证：圆环法线与箭向一致；尖刺基点等距绕轴成圈且指向后方/外侧；改变观察角度不改变几何朝向；箭飞走后发射点不移动。

## 用户确认的默认值（2026-10-22）
刷新页面及恢复试作参数采用：延迟 0 s，环带持续 0.2 s，起始半径 0.35 u，扩张距离 0.95 u，厚度 1.8 倍，白色强度 3 倍；尖刺持续 0.15 s、数量 6、长度 2.8 u、宽度 0.35 u、围绕半径 0.3 u、向外偏角 25°、透明度 0.15；高度偏移 0 u、向前偏移 0.5 u、角色朝向 0°，绿色地面。尖刺透明度范围 0–1，作为生命周期淡出遮罩的独立乘数，不影响圆环。

尖刺长度改为固定基点向外伸长：A 默认 1 u，B 默认 2.8 u，N 默认 0.1 s，按特效出生后的时间线性插值，达到 B 后保持。移除旧的随机长度倍率与额外长度膨胀，确保每根尖刺实际到达 A/B。N=0 时立即采用 B；寿命短于 N 时会在到达 B 前消散。透明度继续沿原有生命周期淡出。

## 游戏接入
游戏与预览器共用 bow-release-config.ts 默认参数与 BowReleaseVisual 网格、遮罩、绝对时间采样代码。箭矢实际生成触发 onFire，使用箭出生位置、实际水平朝向及本步已飞行时间；每支连发箭独立触发，出生即命中也有出箭反馈。对象池复用已结束效果，重置和切场清空。生命周期使用模拟时间，支持调试暂停与慢放。

验证：tools/bow-release-game-check.mjs 比较游戏与预览同龄效果的环带大小、旋转、透明度、宽度、强度及所有尖刺变换，检查三箭连发、池复用、重置及怪物训练场。场景背景、遮挡和动作过渡仍来自实际游戏。

预览新增圆环扩大曲线对比：OutCubic（原有默认，先快后慢）与 Linear（匀速）。曲线图纵向为已完成扩张比例，横向为环带生命周期。切换只影响半径扩张，不改变淡出、厚度、尖刺或持续时间。游戏继续使用原默认 OutCubic。半程验证：OutCubic 扩张 87.5%，Linear 扩张 50%。

2026-10-22 更新：正式游戏与预览共用的环带持续时间改为 0.3 s；扩张继续使用 OutCubic（先快后慢，1−(1−u)³）。尖刺及其他默认参数保持不变。
