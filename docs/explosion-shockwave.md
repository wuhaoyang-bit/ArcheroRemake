# 爆炸空间扭曲冲击波

游戏侧边栏「爆炸 · 空间扭曲冲击波」提供开关、最大半径、时长、波带宽度、扭曲强度、衰减指数和扩散速度曲线，也可点击「在游戏中预览冲击波」。默认在怪物真正爆开的瞬间触发，半径 3.2 单位、时长 0.32 秒、波带宽度 0.75 单位、强度 5 px。像素强度以 390 px 宽游戏画面为基准等比缩放。

冲击波先快速推出，再逐渐减速至停止，同时淡出。曲线纵轴表示相对速度；默认控制点为 `(0,100)、(25,56.25)、(50,25)、(75,6.25)、(100,0)`，近似 OutCubic 的减速趋势。点之间线性插值速度，对速度积分得到半径，并以曲线总面积归一化：`半径 = 最大半径 × 当前累计面积 / 总面积`。因此调整曲线改变扩散节奏，最终范围由半径参数独立控制；全零曲线不产生冲击波。速度始终非负，波带不会回缩。

扭曲强度在前 8% 时间内平滑进入，随后按 `(1 - 时间进度)^衰减指数` 淡出。强度包络与扩散运动独立，避免通过缩小半径来淡出。爆开时记录配置；游戏调参用于下一次爆炸。关闭开关、重置怪物或切换训练场立即清除现有波。支持保存、刷新、撤回及旧参数文件自动补默认值。

`slime-burst-lab.html` 使用同一个渲染器与速度模型，可慢放、逐帧前后查看和编辑速度曲线；修改会重算当前时刻，「保存到游戏」合并保存本页参数。关闭「六层爆开特效」和「地面液滩」后，可以利用地面网格观察纯折射。

实现采用 Three.js WebGPU RenderPipeline：先渲染场景，再对局部环形波带内的画面取样坐标做径向偏移，形成相邻的压缩与拉伸。波带外偏移为零；不额外绘制发光圆环。爆点保留世界坐标，每帧按当前相机投影，随镜头移动、震动、缩放和视口尺寸正确对齐。DOM 界面不参与折射。最多同时保留 10 个波，叠加位移限制为 24 设计像素。无活动冲击波时使用原有渲染路径；加载期间预热效果。

验证：`npm test`、`npm run build`、`node tools/burst-shockwave-check.mjs`。覆盖速度积分和减速趋势、生命周期、多爆点、设置兼容、真实爆炸时序、透明材质、曲线撤回、保存刷新、逐帧回放和窄屏。浏览器以开关前后像素对比检查折射确实发生且限制在波带内；参数请求被拦截，不改实际 `public/params.json`。
