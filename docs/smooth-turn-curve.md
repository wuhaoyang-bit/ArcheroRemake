# 自定义转向曲线－二阶平滑

普通和锁定模型均新增 ID 7，分别读取 `turnCurve / curveSnapAngle` 和 `lockTurnCurve / lockCurveSnapAngle`。不新增可调字段，不更改用户 `public/params.json`，不复用退役 ID 1/3/4；旧模型行为不变。

## 算法与取舍

每段令 `t=(angle-a)/(b-a)`，`S(t)=6t^5-15t^4+10t^3`，实际角速度 `v(angle)=(1-S(t))*v(a)+S(t)*v(b)`，单位 °/s。不是求原曲线二阶导数作为速度。

`S'(t)=30t²(1-t)²≥0`，所以保留全部控制点、段内无负速度及过冲。接点两侧一阶、二阶导数均为零，即使区间长度不同也真正 C2。普通 cubic Hermite/PCHIP 通常仅 C1，不用于此模型。实现从较近端点计算，避免接近零速度时相减丢失精度。

代价：各控制点附近曲线变平，不保留原折线斜率。零速端点附近按距离三次方衰减，可能比线性曲线明显更慢。C2 指速度对角差的函数连续性，不保证到位吸附、目标突变、模型切换时的时间导数连续。0°始终停止，即使其控制点速度非零。

求解 `de/dt=-v(e)`：逐段自适应 Simpson 计算时间 `∫de/v(e)`（时间绝对误差目标 `1e-10 s`、最多 18 层），有界二分反解残余角差（最多 44 次、角宽 `1e-11°`）。恒速段时间直接计算。不按折线积分，不使用 Euler 跨越慢速区。非零零速控制点是不可跨越的平衡点；路径存在该阻挡时禁用吸附，避免到位阈值跳过阻挡。原 ID 2 的解析积分和阈值行为不变。

数值积分成本高于线性解析积分。极端浮点数、极窄区间下，精度受双精度及递归上限限制；不宣称任意输入下数学精确积分。固定目标测试在 30/60/120/240 Hz 的残余角差偏差小于 `2e-6°`。移动目标仍沿用现有模拟步采样，不承诺不同采样率的任意输入轨迹完全相同。

## 界面与保存

修改参数请切回原“自定义转向曲线”。原曲线编辑、恢复默认或撤回后，平滑转向和预览自动更新。平滑模式只显示只读图和“放大预览”，无拖点、双击编辑/加点、删除或恢复默认操作；桌面、手机及放大视图一致。到位阈值也沿用原曲线值，不新增独立控制。

沿用 JSON 版本、缺失锁定字段继承规则及撤回历史，不保存派生曲线或预览状态。移动、移动中换指使用普通曲线；待机/原地跑步且有目标使用锁定曲线。模型没有速度状态，切换时直接读取对应源曲线；切到不同阻尼模型沿用现有清零规则。Android 范围 schema 由现有同步脚本从 `LIMITS` 生成，下次获准打包时才更新安装包。

## 验证

- `npm test`：C2 接点、边界、跨段、帧率一致性、零速阻挡、模型切换、保存校验和撤回；原水平 180° 特判测试也覆盖 ID 7。
- `npm run build`：类型检查及生产构建。
- `node tools/smooth-turn-browser-check.mjs`：两套预览、原曲线编辑与撤回、桌面/手机/放大只读交互、保存重载。
- `node tools/history-browser-check.mjs`：既有九条曲线撤回、放大编辑、保存竞争及失败。
- `node tools/turn-model-browser-check.mjs`：五个选项、原模型调参与保存、操作中切换。

上述浏览器测试拦截参数读写，不写真实 params；专项测试还核对文件字节未变。手机真机性能与手感尚需实际设备验收。本轮不构建 APK、不提交。
