# ArcheroRemake

第一版：用 **Three.js + WebGPU** 复刻《弓箭传说》的角色轮盘移动手感。电脑用鼠标，手机用触摸；两端保持相同的 9:19.5 竖屏构图。具体规则、用户原话与验收依据见 [PLAN.md](PLAN.md)。

## 运行

需要 Node.js 22.12+（已在 Node.js 24 上验证）和可用 WebGPU 的浏览器。

```sh
npm ci
npm run dev
```

电脑打开 `http://localhost:5173`。按住游戏区域任意位置：先原地跑步，拖出首次解锁距离后开始移动；松开立即停止位移。左侧调参，右侧观察状态。

## 保存参数

修改参数会即时生效。点击面板底部的 **保存 JSON**，将当前全部调参值写入项目的 [`public/params.json`](public/params.json)。刷新或重新打开页面时读取这份文件；电脑与同一开发服务下的手机共用它，不依赖浏览器本地缓存。

保存方式参考 SmashBroCER：页面提交参数，Vite 的保存接口写回固定 JSON 文件。文件采用版本化结构，写入时校验数值并以临时文件原子替换，避免写入失败损坏之前的保存；保存不会触发整页重载。面板会显示未保存、保存成功或失败状态。

面板底部 **撤回** 按操作恢复参数，支持数值、模型选项、开关和全部九条曲线（含放大编辑）。一次完整拖动只记一步，未改变参数不记历史。**撤回全部** 恢复本页面最近一次成功保存的参数；尚未保存时恢复页面加载参数（读取失败时为当次使用的初值），同时清空历史。两种撤回都只改内存，不写 JSON。无历史时撤回禁用，与基准一致时撤回全部禁用。仅用于调试的朝向显示开关和圆环播放预览不属于保存参数。

保存成功以提交时的完整快照作为新基准，并清空此前历史；请求期间的新修改仍保留在页面，可用撤回全部回到该快照，之后的操作重新记历史。保存失败不改变基准或历史。尚未保存的修改在刷新后丢弃；多个页面同时保存时，以最后一次成功写入为准，其他页面刷新后读取。仅保存调参值，角色位置、按下状态和移动锚点记忆在刷新后仍清零。

撤回专项验证：`node tools/history-browser-check.mjs`，复用本地开发服务并拦截全部参数读写请求，不覆盖用户 JSON。覆盖完整滑条/九条曲线拖动、放大编辑、键盘、数值及模型选项、保存中的修改、保存失败、读取失败回退和手机面板。

已按确认将 `public/params.json` 中“旋转角速度模型”的 `turnCurve` 控制点复制到“旋转角速度－锁定”的 `lockTurnCurve`，替换原曲线，其他参数不变。这是一次性复制，之后两条曲线仍可独立编辑和保存。

`npm run dev`、`npm run dev:https` 与 `npm run preview` 均支持写回本项目的 `public/params.json`。纯静态部署可读取构建时打包的 JSON；若要在线保存回服务器，需要提供对应保存接口。

## 手机测试

手机和电脑连接同一局域网，然后运行：

```sh
npm run dev:https
```

打开终端显示的 **Network HTTPS 地址（5174 端口）**。手机右上角“调参”按钮展开参数面板。轮盘以最新按下的手指为准，支持多指接管。

WebGPU 需要安全上下文：电脑可使用 localhost；手机通过局域网 IP 访问时需要 HTTPS。开发服务使用自签名证书，手机需要信任该证书；如果浏览器仍不认可该连接，应使用受信任证书的 HTTPS 地址。支持程度以设备实际能否创建 WebGPU 适配器为准。页面会显示初始化失败原因，不会悄悄切换为 WebGL。当前自动化覆盖桌面 WebGPU、手机视口和浏览器多点触摸；**手机真机性能与手感仍需实际设备验收**。

## 离线 Android APK

目标测试机为 REDMI K80 Ultra。APK 直接装入同一次构建的网页、模型和 `public/params.json`，使用系统 WebView 的 WebGPU 渲染，保留相同的竖屏视角、触摸逻辑和调参界面。首次启动读打包的 JSON；点击“保存 JSON”后写入应用私有目录，退出重开仍有效，不需要电脑或服务器。之后电脑修改 JSON 不会自动同步到已安装的 APK。

覆盖安装且签名一致时保留手机已保存参数；卸载或清除应用数据会删除它们。下次明确要求打包后，撤回与撤回全部沿用网页规则。只有参数持久化，角色位置及锚点记忆不保存。

构建需要 JDK 17、Android SDK Platform 36 / Build Tools 36.0.0，并设置 `JAVA_HOME`、`ANDROID_HOME`。当前电脑在忽略目录 `analysis/android-toolchain/` 已准备工具链，脚本会自动识别。

```sh
npm run android:build
# 输出 releases/ArcheroRemake-v0.1.0-debug.apk
```

这是供直接安装测试的 debug 签名包。脚本首次生成的本地测试签名位于 `analysis/android-toolchain/archero-debug.keystore`；请保留它，以便后续覆盖安装。SDK、密钥、构建缓存和 APK 均不纳入 Git。构建前会校验网页资源复制后的每个字节，并保留资源 SHA-256 清单。

手机仍须有支持 WebGPU 的系统 WebView；不支持时显示错误，不降级为 WebGL。相同代码、素材和参数可通过构建校验确认，REDMI K80 Ultra 的实际画面、触摸延迟和帧率仍需真机验收。安装后可断网测试移动、多指接管、保存后重开，以及切到后台再返回时是否正确结束输入。

## 已实现

- 按下点定位轮盘、首次阈值锁定、越阈值瞬时解锁、边缘限幅；解锁后不重复触发死区。
- 待机／原地跑步／真正移动，与摇杆锁定状态分开管理。
- 固定速度、立即位移、身体按最短角度转向；松手后身体继续转完。
- 正常松手以该事件携带的最终鼠标／触点坐标直接计算锚点（经过半径限制与地面映射，不读取摇杆显示位置），再立即停止位移；目标朝向始终由锚点决定，待机时也继续转完；旧手指松开和取消操作不会覆盖当前方向。失去指针捕获时立即停止位移，但保留同次操作的收尾信息，仍接受随后到达的最终松手坐标；新按下、取消或窗口失焦会清除待收尾信息。
- 可见移动锚点、角色相对偏移记忆、松手隐藏；精确居中时保留最后方向继续移动。
- 最新手指接管；移动中换指延续旧方向，直到新摇杆解锁；旧指永不恢复控制。
- Idle／Run 骨骼动画融合；中途反向融合从当前权重继续，原地跑步进入移动不重启动画。
- Run 动画播放倍率独立可调，原地跑步与真正移动共用该倍率；Idle、融合时长、实际位移速度各自独立。
- 宽度与纵向长度独立可调的长房间；固定横向镜头，仅纵向平滑追近，房间上下边缘不截断跟随。
- 地面两轴同尺度映射，再由倾斜正交镜头自然投影；没有第二次纵向压缩或逆向角度补偿。
- 指针捕获、失焦／取消清理、屏幕边缘轮盘保持原始按下位置、调参控件隔离。

锁定训练场支持松手后循环播放射箭动作；当前没有箭矢、伤害或敌人战斗逻辑，也没有键盘移动。

## 可调参数

像素以 390 宽的游戏视口为基准，在不同设备上等比换算。世界单位仅用于本项目。

| 参数 | 初值 | 含义 |
| --- | --- | --- |
| 摇杆半径 | 64 px | 摇杆最大偏移 |
| 首次解锁距离 | 12 px | 每次按下／接管后需严格超过该距离 |
| 地面映射比例 | 0.036 单位/px | 限幅后的摇杆偏移到地面两轴的统一比例 |

| 转向速度 | 900°/s | 身体最短角度转向速度 |
| 动画融合 | 0.06 s | Idle／Run 的姿态融合时长 |
| Run 动画速度 | 1.6 倍 | 可调范围 0.25～4；只改变 Run 播放节奏 |
| 房间宽度 | 16 单位 | 横向边界；角色脚下留 0.46 单位碰撞半径 |
| 房间纵向长度 | 38 单位 | 画面上下方向，可独立调整至 8～80 |
| 显示移动阈值范围 | 关闭 | 黄圈表示首次解锁范围，解锁后变青色；开关随 JSON 保存 |
| 跟随响应 | 9 s⁻¹ | 按位置差指数收拢，越大越紧跟 |
| 脚下目标线 | 0% | 默认画面中线；正值下移，负值上移 |
| 固定视野宽度 | 18 单位 | 手动校准；游玩中不自动缩放 |

默认镜头为倾斜正交投影，高度 24，相对地面的俯视夹角约 55.1°，使地面两轴的屏幕投影长度比约为 0.82。此数值只用于本版画面初始校准，不代表已经证明原作的内部参数。刷新后调参值从 JSON 恢复，角色运行状态和锚点记忆重新初始化。

## 旋转角速度模型对比

两套下拉栏支持：匀速转向（ID 0）、自定义转向曲线（ID 2）、Slerp（ID 5）、SmoothDampAngle（ID 6）、自定义转向曲线－二阶平滑（ID 7）。旧模型 ID 1/3/4 读取时仍回退到匀速，不复用退役编号。Slerp 和 SmoothDampAngle 使用独立字段；ID 7 仅复用各自已有曲线与到位阈值，不增加参数。算法与取舍见 [二阶平滑说明](docs/smooth-turn-curve.md)。

Slerp 使用 Three.js 的四元数球面插值，对应 Unity 的 `Slerp(current, target, Clamp01(response * dt))`。每次从当前朝向追赶最新锚点，不保留固定起点。它与 `1-exp(-k*dt)` 的指数模型不是同一离散公式，响应会受更新步长影响。角色只绕竖直轴转动，使用已选择最短弧的相对旋转，以保留水平 180° 特判。

SmoothDampAngle 使用 Unity SmoothDamp 的不限速递推，保留有符号角速度。最短角差由控制器计算；沿用项目约定：反向目标清除反向惯性，到位阈值内对齐并清零速度。这两项是项目保护规则，不冒充 Unity 原生行为。松手/换指不会清零同向速度，待机继续朝保留的锚点转身。模型切换只清零内部角速度。

默认参数沿用此前确认的取舍：纯公式无法同时达到第 4 帧 90°和第 9 帧到位，优先第 9 帧进入 0.1°。以下均为 180°固定目标、从静止开始、60 FPS、每帧两个 1/120 秒模拟步：

| 模型 | 默认参数 | 第 4 帧累计转角 | 第 9 帧 |
| --- | --- | --- | --- |
| Slerp | slerpResponse=40.872 /秒，slerpSnapAngle=0.1° | 约 173.6° | 对齐 180° |
| SmoothDampAngle | smoothTime=0.03039 秒，smoothSnapAngle=0.1° | 约 168.0° | 对齐 180° |

Slerp 系数由 `120 * (1 - (0.1/180)^(1/18)) = 40.871529…` 求得，向快的一侧取整。SmoothDampAngle 平滑时间按实际递推数值求解。平滑时间不是固定完成时长，持续移动的目标不保证 9 帧到位。可在调参面板调整两套参数并保存 JSON。实际位移、输入锚点、动画、镜头不随模型切换改变；本次不构建 APK。

验证：`npm test`、`npm run build`、`npm run test:turn-model`。浏览器保存测试拦截参数请求，不改用户 JSON。

自定义曲线保留双击加点、双击点编辑、拖动、放大编辑及不可删除的 0°/180°端点。原“从当前指数参数生成曲线”改为“恢复默认曲线”，明确恢复初始 10.4 响应生成的曲线及 0.1°阈值；只有点击按钮才覆盖当前曲线。非零角度零速度可能停转；0°始终停止。

## 障碍物训练场

游戏顶部“障碍物训练场 / 返回普通训练场”按钮切换场地。障碍场从底部开始，纵向间隔放置程序几何制作的大笑黄色奶龙风格障碍物（非原版模型素材），地面等规格圆滑曲线引导交替绕行，每个侧向拐点设白圈；从下往上依次进入圈内后，白圈及通往它的路径变绿，重开清空进度。障碍有圆形碰撞，可沿边缘滑动；目标锚点仍由玩家输入决定。抵达顶部棋盘终点线即成功，显示提示并自动回到底部，需重新按下开始下一轮；不强制逐个路线检查点。

房间宽度、纵向长度调整时同步重建障碍与路径。场地切换和成功重开清空当前操作及锚点记忆，保留调参；训练场选择和完成次数不写入参数 JSON。测试：`node tools/training-browser-check.mjs`。本次不更新 APK。

白圈反馈：下一个目标圈带轻微呼吸光环；通过时播放约 0.7 秒的扩散光环，已完成路径从浅亮绿回落至常态绿。动画只影响显示，白圈触发半径、路径和移动逻辑不变；重开或切场清除反馈。

## 锚点防抖跟随

调参面板“锚点防抖”可开关跟随，并编辑距离差／速度曲线：拖动控制点实时调整距离和速度（0 距离端点仅上下移动），双击空位加点、双击点输入数值，也可使用添加、编辑、删除、放大按钮。拖动期间固定坐标轴，避免图表缩放导致控制点跳动；控制点不能越过相邻点。距离单位是地面单位，速度单位是地面单位/秒。最后一点以外保持该点速度，因此最后一点的距离可作为快速追赶区的起点。默认在 0.6 单位以上以 30 单位/秒追赶；内部控制点逐渐减速，抑制短暂小抖动。低速跟随不等于死区，持续小偏移会逐渐追上；非零距离设置零速度可导致不再追近。

拖动先更新目标锚点，实际锚点按曲线追赶；二者使用相对角色、与身体朝向无关的坐标。移动和转向只读实际锚点。从原地移动解锁时立即同步实际/目标锚点。松手按最终鼠标/手指坐标经过原有半径限制及地面映射，立即同步两者、停止位移，身体继续转向；捕获丢失先于松手时，后续最终坐标仍可纠正锚点。

换指锁定期间冻结实际锚点及跟随目标；若角色已在真正移动，再解锁时恢复跟随，不触发原地起步特判。取消而没有最终坐标时冻结实际锚点，停止未完成的跟随。关卡重开清空二者。默认启用，关闭可对照此前直接映射。anchorFollow 与 anchorCurve 随 JSON 保存；旧文件补默认，右侧显示目标锚点及跟随距离差。本次不更新 APK。

## 移动速度模型

调参面板新增“移动速度模型”：恒定移动速度／角度差曲线。默认保持恒速；曲线初始 0°～180°均为 100%，因此即使切到曲线模型，速度仍与当前基础移动速度完全一致。横轴是身体与实际移动锚点方向的最短角度差；纵轴是基础移动速度百分比（例如 80 表示八成速度）。拖动、双击输入、加点、删除内部点、放大编辑和恢复默认均可用；0°、180°端点不可删除。

每个模拟步先更新实际锚点，再根据转身前的当前角差读取分段线性倍率，位移速度=基础移动速度×倍率；位移方向仍由实际锚点决定。0%可停止位移但不会阻止身体继续转向。转向模型、Run 动画速度和锚点跟随参数保持独立。右侧“移动指令速度”显示本次模拟步的速度指令，碰墙时不等于实际位移速度。moveModel、moveCurve 随 JSON 保存，旧文件补默认。切换模型不会重置角色、输入或锚点；本次不更新 APK。

右侧速度监测同时显示当前角度差、移动计算角度差（该模拟步转身前的采样值）、移动速度倍率、相对基础速度减少的单位/秒与百分比。减速数值与当步实际采用的倍率一致，恒速模型显示减少 0；未移动时显示“—”，不把松手停止误记为曲线减速。碰撞造成的位移损失不计入该值。

## 锁定训练场

右上角新增“锁定训练场”按钮，可与普通训练场、障碍物训练场互相切换。以房间中心为基准，上、下、左、右及四角各布置一个静态木制假人，靶面朝向中央；位置随房间宽度与纵向长度调整，左右留 2 单位，上下最多留 4 单位（短房间按纵长四分之一），让上方假人与顶部按钮留出空间。角色进入时从中央开始，中心有地面标记。

进入场地时不选敌，第一次按下游戏区域后启用选敌，之后待机/原地跑步/移动都运行。待机或原地跑步且有目标时，身体使用独立的锁定转向配置朝敌人旋转；按下后在阈值内继续朝敌人转向，越过阈值进入真正移动才恢复普通配置朝实际移动锚点旋转。无目标时仍使用普通配置朝锚点旋转。移动中换指仍处于真正移动状态，继续朝锚点转向。锁定不改写移动锚点或移动方向。沿用已有移动速度模型：恒速保持原速度，角度差曲线仍按身体与实际锚点的夹角计算。

调参面板“目标锁定”提供三种实验模型（非原作算法断言）：

- A 最近目标：范围内每步选择最近假人。
- B 方向扇形：取实际锚点方向扇形内夹角最小者，同角度取更近者；扇形内无候选时无目标。
- C 方向＋保留条件：候选排序同 B；新候选须比旧目标具有正的角度优势、达到优势阈值，并连续满足指定时长才切换。旧目标在距离范围内可继续保留在扇形外；同角度更近不会触发切换。松手清零候选计时，但保留当前目标，之后可重新累计。换指不清零计时。旧目标失效立即按方向规则重新选敌，不等待时长。

范围使用双方脚下中心的地面距离，屏幕外目标仍参与。初值 22 单位可调整，“显示锁定距离范围”显示角色脚下圆周；B/C 扇形总角默认 90°，C 优势 8°、持续 160ms，均可调。首次锚点与角色重合时使用角色初始朝向，之后零偏移保留最后有效锚点方向。已启用时切换选敌模型立即重选；重新进入场地恢复等待首次按下。

红色屏幕圆环显示当前目标，浅色圈显示 C 待确认候选。游戏上方显示目标名称，右侧显示启用状态、模型、目标距离、候选计时和当前转向配置。手机通过“调参”打开面板。选敌参数与独立的锁定转向模型、曲线和数值均通过“保存 JSON”持久化；旧 JSON 首次加载时将当前普通转向配置复制到缺少的锁定字段，之后两者独立。运行中的目标、计时和启用状态不保存。

“旋转角速度－锁定”支持匀速、自定义曲线、Slerp、SmoothDampAngle。两套配置均为 SmoothDampAngle 时继承角速度并沿用反向清零保护；切换到不同模型时清除内部速度，身体朝向保持连续。切场清理目标、手势和锚点，保留调参。假人没有碰撞，本次不更新 APK。

有有效锁定目标时，当前操控手指或鼠标左键松开，立即停止位移、沿用锁定配置转向目标，并同时开始循环播放射箭动画；不等待身体转完。动作来自模型的 `AttackPrev → AttackEnd`，每轮约 1.05 秒，保持松手且有有效目标时连续循环，不在两轮之间切回 Idle。只有有目标时真正的松手事件开启循环，按下、阈值内原地跑步、旧手指松开、取消/失焦、自动选到目标都不会开启新的攻击循环。失去所有有效目标时停止攻击并回到 Idle；若同次松手期间重新获得目标，则恢复循环。攻击中再次按下立即打断并切回 Run。动画融合沿用现有参数，Run 倍速不影响攻击。当前使用截图对应的红色简约弓 `WeaponHand1001 / gong`（124 顶点），通过前方手部挂点跟随角色。原始 `weapon1001_prev/end/reset` 缩放曲线接入同一个动画混合器：蓄力结束对齐 0.55 秒的释放点，随后按原速回弹，待机、跑步与攻击中断均恢复原形。这里的形变是整弓非均匀缩放，没有新增弓弦或骨骼弯曲。本次只播放动作，不产生箭矢或伤害。

验证：`npm test`、`npm run build`、`npm run test:character`、`npm run test:attack`、`node tools/targeting-browser-check.mjs`、`node tools/locking-training-browser-check.mjs`。浏览器调参与保存测试拦截 JSON 请求，不覆盖用户参数。

保存接口支持九条各最多 128 点的曲线，JSON 请求上限为 64 KiB。Android 存储桥接源码同步保存九条曲线，下次明确要求打包时随 APK 生效。


### 双圆锁定 UI

首次获得目标时，角色红圈直接显示最终大小，目标红圈从包住整个游戏视口的尺寸收缩；默认时长 0.25 秒，开始快、接近终点放缓。换目标仅跳转圆心，保留当前收缩进度；丢锁隐藏两圈，再次锁定重新入场。替代旧橙色脚下目标圈，保留候选提示和范围调试圈。

“锁定圆环 UI”可独立调整双方直径、描边粗细、固定圆心高度、收缩时长和时间进度／收缩完成度曲线。支持拖点、双击加点、双击数值编辑、删除中间点及放大编辑；起终点固定，完成度不能倒退。所有圆环参数在下一次入场统一生效，换目标不提前应用。“保存 JSON”保存下一次使用的配置。

圆心按脚下位置加固定世界高度投影，不跟随动画骨骼；圆环覆盖模型且不阻挡触摸。尺寸和线宽按 390 宽基准缩放，窗口变化不重播收缩。新增参数缺失时读取默认值，不覆盖已有实验参数。本次未更新 APK。

检查：`npm test`、`npm run build`、`npm run test:lock-rings`（需运行本地开发服务和安装 Chrome）。


### 圆环粗细曲线与收缩预览

“锁定圆环 UI”新增“目标圆粗细 / 收缩完成度”曲线。横轴为几何收缩完成度 0～100%，纵轴为目标基础线宽的 0～1000%；默认 100% 水平线保留原有粗细。实际线宽 = 基础线宽 × 曲线倍率。两个端点可调粗细、不能删除；支持拖动、双击加点、数值编辑和放大。角色小圆不受此曲线影响。曲线仍在下一次入场取配置快照。

曲线下方进度条无目标时禁用并变暗，有目标时显示实时收缩完成度和实际线宽。拖动后冻结圆环在指定完成度，点击“恢复自动播放”从该完成度继续原收缩曲线；换目标保留预览，丢锁或切场退出。进度条直接控制几何完成度，50% 表示从初始半径到最终半径走过一半，不是播放时长的一半。预览不改变角色移动、选敌或攻击，也不保存到 JSON。

检查：`node tools/ring-stroke-browser-check.mjs`。本次只更新网页与 Android 保存桥接源码，未打包 APK。

目标圆收缩完成度达到“连线出现完成度”（默认 95%）时，显示两个圆心方向上的红线。“连线粗细”独立调整，默认 1 基准像素。线段截在两圈描边外缘，圆内不绘制；两圈相交或重合时隐藏。连线跟随圆心和当前半径更新，换目标同步跳转；丢锁隐藏。手动预览退回阈值以下也会隐藏。两项参数可保存 JSON，沿用下一次入场生效规则。


### 攻击动画驱动的连线粗细

“连线粗细 / 攻击动画进度”提供独立倍率曲线（0～1000%），横轴是实际攻击动画一轮的播放进度。默认 100% → 蓄力末端 65% → 松弦附近快速升至 145% → 恢复 100%。曲线支持拖动、双击加点、数值编辑、删除内部点与放大；首尾值相同可避免循环处跳变。

图中标注蓄力、松弦参考与恢复阶段，蓝色游标跟随动画，同时显示秒数与按素材 60 FPS 换算的帧号（从 0 起算）。松弦参考取 `AttackPrev → AttackEnd` 拼接点，约 0.55 秒／52.38%／第 33 帧；这是素材阶段分界，并非已确认的精确发射事件。总时长约 1.05 秒。

实际连线粗细 = 基础线宽 × 动画进度曲线倍率，并按攻击动画混合权重从基础线宽过渡。攻击中断或未播放时为基础线宽；动画循环自动重复效果。沿用连线出现阈值和圆内不绘制规则。参数保存 JSON，下一次锁定入场生效；播放游标不保存。验证命令：`node tools/link-attack-browser-check.mjs`。


### 换目标圆环脉冲

完成首次收缩后切换目标，目标圆心立即跳转，同时快速扩张再收紧。默认总时长 0.25 秒、额外放大幅度 150%（最大尺寸 250%）。面板提供“换目标动画时长”“换目标额外放大幅度”和“换目标扩张 / 时间进度”曲线；0 幅度关闭效果。

曲线横轴为动画时间百分比，纵轴为额外扩张量百分比，上升扩张、下降收紧，斜率控制各阶段速度；首尾固定 0，内部点可拖动、双击添加或输入数值。默认时间 25% 到达最大扩张，随后减缓收回。连续换目标从当前尺寸衔接，最大不超过设置幅度；初次收缩中换目标不叠加脉冲。角色圆及连线攻击节奏不变，连线裁切跟随目标圆当前大小。

参数保存 JSON，下一次锁定入场应用。手动拖动入场进度条清除并抑制换目标脉冲，退出手动预览后恢复正常换目标反馈。丢锁、切场清理脉冲。本轮未更新 APK。检查：`node tools/ring-switch-browser-check.mjs`。


### 换目标冲击波

换目标脉冲达到实际最大半径时生成独立红色冲击波，每次脉冲一次；峰值按可编辑换目标曲线计算，跳过峰值帧也能触发。默认 0.4 秒向外增加 32 基准像素半径，初始线宽 1.2 像素；扩散进度默认先快后慢，线宽随扩散进度减至零后移除。

“冲击波扩散 / 时间进度”曲线支持拖点、双击加点与输入数值；横轴时间、纵轴扩散完成度，斜率决定扩散速度。可独立调整时长、扩散距离、初始粗细。0 距离或 0 粗细关闭效果。参数保存 JSON，下一次入场生效。冲击波跟随当前目标圆心；换目标、丢锁、切场、手动收缩预览清除旧波。初次巨圆收缩不产生冲击波。本次未更新 APK。
