# ArcheroRemake

复刻《弓箭传说》（Archero）手机虚拟摇杆的操作手感。第一版聚焦角色移动，计划采用 Three.js + WebGPU，支持电脑鼠标与手机触摸测试。

当前阶段：操作规则、角色动画、镜头与地面映射方案已完成对齐；本仓库目前保存项目说明和制作计划，游戏实现尚未开始。

## 已确认的第一版范围

- 按下位置决定轮盘中心，首次越过阈值后解锁，解锁后保持到松手或新触点接管。
- 区分待机、原地跑步和真正移动；固定移动速度，身体独立按最短角度转向。
- 移动锚点按角色相对位置计算，支持偏移记忆、显示时机和多指接管规则。
- 使用限制后的摇杆偏移，按同一比例映射到地面两轴，再由倾斜正交镜头自然投影。
- 现成低多边形角色，Idle／Run 动画融合，默认融合时长 0.12 秒且可调。
- 可调方形房间；镜头横向固定、仅纵向平滑跟随，房间上下边缘不截断镜头跟随。
- 电脑和手机使用相同竖屏构图，电脑两侧提供调试面板。

具体行为、用户原话依据、实现顺序和验收条件以 [PLAN.md](PLAN.md) 为准。
